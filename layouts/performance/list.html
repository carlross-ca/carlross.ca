How to read these numbers

Return: time-weighted return (TWR). It separates investment performance from deposits and withdrawals.

Below previous peak: the current decline from the highest point of the return record. Largest decline: the deepest peak-to-trough fall during this record, also called maximum drawdown. A more negative number means a larger decline.

The S&P 500 Total Return Index includes reinvested dividends and is translated into CAD. It is a reference benchmark; it does not have the same holdings or risk as this portfolio. Public figures are before tax. After-tax results and time spent are not yet measured here.
